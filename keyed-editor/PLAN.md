## Frozen shared contract

Go package `collection` owns State{Rows []Row,NextID uint64,NextRequestID uint64}. Row{ID uint64,Draft string,Saved string,Saves int,PendingID uint64,Status string}. IDs positive JS-safe <=9007199254740991, monotonic and never reused across delete/reset. Init has Rows=[] and counters0. MaxRows=4 is enforced in Go; Add is disabled/no-op at4 rows, otherwise creates an empty idle row. Reset removes all rows and cancels pending requests in row order, preserving both counters and request→row history. Remove cancels that row before removal. Up swaps with preceding row, first-row Up disabled. Edit changes Draft only. Save nonempty Draft cancels its old pending request then allocates a fresh request ID and start command capturing Draft. Cancel clears PendingID/status=cancelled, keeps saved/draft. Overflow rejection is atomic before cancellation/state/message/outbox mutation.

Reuse gobi.Node/On/Message, inputbinding.View/Binding/Resolve, asyncsave.Command/Reply and httpwire.EncodeRequest/DecodeResponse. New Go Session provides NewSession, Snapshot, Dispatch, Complete, Effects, Audit. Snapshot EXACT standard keys `{state,tree,bindings,messages}`; messages cumulative nonnull[]. State Rows always nonnull[]. Commands outbox drained/copied. Reply audit cumulative Outcome{ID,RowID,Value,Error,Accepted,Reason}; retain request→row mapping so late removed-row reply reports original RowID. Reply accepted only if row exists and PendingID==reply.ID. Accepted error: PendingID0, Status='error: '+Error, keep Saved/Saves; accepted success: Saved=Value,Saves++,Status=saved,PendingID0. Unknown/stale reply adds `reply` message Arg=decimal requestID and audit Reason=stale, no row mutation. Invalid IDs reject atomically.

Dispatch wire is EXACT `{Path,Event,Value,Key}` primitive strings. The Go dispatcher resolves the current tree path, verifies target Node.Key==Step.Key FIRST, then suppresses disabled targets, then resolves declared binding/literal handler. A stale path+old key must never edit a different row and must reject atomically. All element keys are nonempty globally unique ASCII tokens `[A-Za-z][A-Za-z0-9-]{0,63}`; text keys empty. Keys never rendered as DOM attributes. Go validates keys and bindings. Edit Binding.Message='edit/'+decimalRowID, Arg comes only from target.value; buttons' gobi.On.Message=add/reset/save/remove/up/cancel and static Arg=rowID (empty for add/reset). Go owns application identity; JS sends event path/key/value only.

View EXACT shape (standard Go Node fields/nil arrays, same existing bounded tags/attrs): root div Key=collection class=collection, children button0 Key=add class=add text='Add row'; button1 Key=reset class=reset text=Reset disabled iff Rows empty; div2 Key=rows class=rows containing row divs in state order. Row div Key='row-ID' class=row, children: input0 Key='row-ID-input' attrs type=text,value=Draft,aria-label='Row ID'; p1 Key='row-ID-saved' children TWO texts 'Saved: ',Saved; p2 Key='row-ID-saves' TWO texts 'Saves: ',decimalSaves; p3 Key='row-ID-status' ONE text 'Status: '+Status; p4 Key='row-ID-pending' ONE text 'Pending: '+decimalPendingID; button5 save,6 remove,7 up,8 cancel. Button keys 'row-ID-save/remove/up/cancel', class same action, text Save/Remove/Up/Cancel; disabled save iff Draft empty, up iff index0, cancel iff PendingID0. Attr order class then disabled. Input tree attrs order type,value,aria-label; mounted DOM must follow existing React-compatible ordinary attrs then type/value order. Empty rows container Kids=nil. Bindings one per row at `2/i/0`, Source=target.value. Row p attrs nil.

New global `gobiCollection` APIs init(),snapshot(),dispatch(step),complete(reply),effects(),audit(),encodeHTTP(id,value),decodeHTTP(id,status,body). Strict bridge exact arg counts/primitive types/fields, exotic getter failure containment and atomic invalid call behavior. Reuse existing Go HTTP codec unchanged. Native stub for go test ./...; real Node22 WASM smoke. No global gobiHTTPSave modifications.

## Browser contracts and focus

E2 protocol wraps/reuses controlled-input/protocol.mjs validation by validating a clone with keys stripped, then independently validating original keys globally; keep original snapshot keys. Export validateSnapshot,clone,normalizePath,nodeAtPath plus helpers agreed early. Use logical key/path lookup, no extra rendered data-key attributes. Snapshot shape remains four fields.

Renderer mounts `(root,runtime)` where facade has init/dispatch. Return update(snapshot),snapshot(),domSnapshot(){html,disabled},click(path),unmount(). DOM and React map finite Node trees, never Row domain transitions. Update validates before mutation. Within same backend, retained keyed element objects must survive editing/reorder/async completion; removed nodes/handlers fenced. Old detached input events cannot reach Go. Moved nodes use their CURRENT path/key on next event. Explicit old-path/old-key raw dispatch must fail Go identity validation even if path is reused.

Capture focus/selection by active logical key + selectionStart/End/Direction; restore only when that key still exists, is enabled and supports selection. Retained input value must not be redundantly assigned. Within updates preserve actual element identity AND logical focus/selection; across backend replacement actual nodes change, but restore logical input key/selection. Deleting focused row must not focus a different row. Tests compare logical focus only under explicit focus/selection actions, avoiding invented focus semantics for native mouse clicks/disabled buttons.

E3 `createKeyedHost(root,runtime,renderers,transport,initialBackend='dom')` reuses existing effect-host semantics, runtime ownership lease, generation fencing, queued outbox/completion pumps, error reporting and cleanup. Renderer facade init returns cached Go snapshot (one underlying init). Synchronous event returns next snapshot and renderer calls update. HTTP completion calls selectedRenderer.update(next), never remount. Backend swap remounts while caching Go state and restoring focus/selection by key. Failed updates/lifecycle fence; cleanup still possible; no transactional rollback claim. Reuse unchanged http-effects/transport.mjs and httplab/cmd/http-lab. No production HTTP service or generic Backend.Emit claim.
