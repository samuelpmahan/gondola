# E4 independent reference and scripts

## Delivered

- `model.mjs` owns an independent JavaScript collection state machine, request-to-row history, per-row save/cancel semantics, cumulative messages and audit, and the four-field Go snapshot projection. It does not import the Go model, WASM, protocol validators, or candidate renderers. HTTP encode/decode delegates to the existing independent codec in `http-effects/reference.mjs`.
- `reference.mjs` exports `createCollectionReference`, `createCollectionReferenceRuntime`, `mountReference`, and `mountCollectionReference`. The mounted React 19 app owns only the reference model and projection. It renders row identities as React keys, never as DOM attributes; its current event closures send path, key, and input value. Completion updates the same keyed React root. `focusState()` exposes the active key/path and selection for the cross-run harness.
- `scripts.mjs` and `scripts.test.mjs` define bounded fixed scenarios plus reproducible random scripts for seeds `20261030` and `20261031`. The fixed actions include row creation, edit, reorder, focused deletion, pending saves and completion, repeated save/cancel, reset identity nonreuse, backend swaps, stale path/key and detached input, HTTP success/error/wrong-ID/malformed/status/drop, and Add disabled at four rows.
- `reference.test.mjs` checks the exact empty wire shape, row projection and reordering, independent pending requests, late request-to-row audit, per-row completion, invalid dispatch atomicity, four-row limit, and codec API. `reference.browser.test.mjs` checks the real React reference in Chromium, including retained input object identity, selection across reorder/completion, detached event suppression, stale key/path rejection, HTTP codec calls, and disabled Add at capacity.

## API and action schema

`createCollectionReferenceRuntime()` returns `init`, `snapshot`, `dispatch({Path, Event, Value, Key})`, `complete({ID, Value, Error})`, `effects`, `audit`, `encodeHTTP`, and `decodeHTTP`. `mountCollectionReference(container)` returns those model operations plus `domSnapshot`, `focusState`, `inputForKey`, `click`, and `unmount`; its `complete()` synchronously refreshes the existing React root.

Scripts use `{kind:"add"}`, `{kind:"reset"}`, `{kind:"fill",rowID,value}`, `{kind:"click",action,rowID}`, `{kind:"mode",mode}`, `{kind:"release",id,mode,expectedStatus}`, `{kind:"swap",host,backend}`, `{kind:"focus",rowID,selectionStart,selectionEnd,selectionDirection}`, `{kind:"raw-dispatch",step}`, and `{kind:"detached-input",rowID,value}`. HTTP modes follow the existing `httplab` values. Row actions reference the never-reused logical row ID; the harness computes the current path from the snapshot.

The root coordination amendment caps each actor at four rows so controls retain HTTP connection capacity. Add is disabled at four rows and a disabled Add dispatch changes no state, ID, message, or effect.
