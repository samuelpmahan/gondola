# E1 — Go-owned keyed collection

**Status:** producer source frozen after native package and real-WASM bridge checks. No Git operation was performed.

## Delivered API

- Package `collection` owns `State{Rows, NextID, NextRequestID}`, keyed `Row` state, the keyed `gobi.Node` view, input bindings, dispatch, async commands, completion acceptance, request-to-row history, and audit.
- `RowID` and `RequestID` are distinct named Go types. Their wire representation remains a JavaScript-safe JSON number.
- `MaxRows` is a typed `RowLimit` constant set to `4`. At capacity, Add is rendered disabled and a correctly keyed Add dispatch is a no-op with no message or effect. The pure internal transition also rejects an add at capacity before allocating an ID.
- `Dispatch` resolves the current path, checks current `Node.Key` equality before disabled suppression and `inputbinding.Resolve`, then commits a transition only after its validation and allocation checks succeed.
- `Snapshot` returns the four-field lower-case envelope and fresh mutable slices. `Effects` drains and copies commands; `Audit` copies completion outcomes. Valid late replies retain their original row ID after removal or reset.
- `cmd/collection-wasm` publishes `gobiCollection` with strict `init`, `snapshot`, `dispatch`, `complete`, `effects`, `audit`, `encodeHTTP`, and `decodeHTTP` methods. It reuses `asyncsave.Command`, `asyncsave.Reply`, and the unchanged `httpwire` codec.
- The real-WASM boundary smoke is `cmd/collection-wasm/smoke.mjs`.
