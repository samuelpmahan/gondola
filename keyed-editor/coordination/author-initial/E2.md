# E2 — keyed protocol and DOM renderer

## Delivered

- Added `keyed-editor/protocol.mjs`, which validates the inherited controlled-input snapshot contract on a validation copy with element keys blanked, then validates original element keys as globally unique ASCII tokens. Text and fragment keys must be empty; returned snapshots retain their original keys.
- Exported the shared protocol helpers `validateSnapshot`, `clone`, `normalizePath`, `nodeAtPath`, `keyAtPath`, `pathForKey`, `bindingAt`, `literalHandlerAt`, `isDisabled`, and the Node kind constants.
- Added `keyed-editor/dom.mjs` with `mountKeyedDOM(root, runtime)`. It retains elements by global key across child reorders, applies changed input values only when the declared value changes, maps event targets to their current child path and key, and restores input focus and selection by logical key.
- Renderer API: `update(snapshot)`, `snapshot()`, `domSnapshot() -> {html, disabled}`, `click(path)`, `focusState()`, `restoreFocus(state)`, `lastError()`, and `unmount()`.
- Exported `captureFocus(root, keyForElement)` and `restoreFocus(root, state, elementForKey, enabledForKey)` for the React renderer and host. Keys are not written to DOM attributes.
- Added protocol and DOM tests for schema reuse, global key validation, keyed identity and reorder, unchanged input-value writes, current path/key dispatch, removed/detached event fencing, focus/selection restoration, focused-row deletion, disabled clicks, and rejected updates.

## Limits

- DOM identity/focus tests use a purpose-built fake DOM. Real browser identity, native focus behavior, and stale Go path/key rejection remain for the E5 browser/Go-WASM harness.
- The renderer supports the bounded tags and attributes accepted by the inherited controlled-input protocol. IME composition, other browser engines, and pixel-level rendering are not covered here.
