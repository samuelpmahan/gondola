## Choices and bounded contract

Chosen over another JS framework: Go renderer provides a second compiled Go implementation boundary without new JS dependencies. Chosen over generic Backend.Emit compiler: formalize the already executed keyed subset first. User explicitly authorized autonomous scoped development/review; no approval hold or question is required. This is a new additive versioned profile, not a change to existing Gobi types or prior tests.

Go package `rendercontract` exposes `DefaultManifest() Manifest`, `ParseSnapshot([]byte) (Snapshot,error)`, `ValidateSnapshot(Snapshot) error`. Strict parser rejects missing/extra fields, wrong primitive/null types where not allowed, duplicate JSON fields and malformed/trailing JSON. Preserve ordinary Go null arrays on Node; bindings/messages nonnull arrays. Reuse inputbinding validation, add keyed and finite HTML rules.

## Third backend bridge (E2/E3 shared seam)

Package godom with js/wasm implementation and native stub plus cmd/godom-wasm publishes global `gobiGoDOM`. Singleton active renderer per browser realm, all methods strictly validate argument counts. Methods mount(root,facade), update(snapshot), snapshot(), domSnapshot(), click(path), focusState(), restoreFocus(focus), unmount(). Return native JS JSON values; wrap errors as exact {error:string}; successful mount/update/unmount/restoreFocus return null or snapshot (adapter ignores mutation returns). JS adapter unwraps errors. Facade init/dispatch/optional rendererFailed exactly existing keyed host semantics. Go backend decodes snapshots through rendercontract and treats State as opaque; no collection imports or row-specific transitions.

Go backend owns keyed DOM reconciliation, event callbacks and cleanup, controlled values, disabled behavior, actual input object retention, current path/key routing, focus selection preservation. Copy operational semantics from JS DOM but implement in Go using syscall/js and typed gobi.Node, not a JS DOM renderer delegation. Attr order follows React: ordinary attrs then input type/value; input.value only assign if different. Removed listeners cannot dispatch. Real callback errors fence backend and notify facade.rendererFailed nonthrowingly; host-invoked errors propagate. All callbacks released on removal/unmount. First dependency gate is a real browser spike proving two Go WASM runtimes can synchronously nest renderer event→facade→Go app dispatch→renderer update. Report exact limitations rather than concealing a block.

`renderer-conformance/adapter.mjs` exports async loadGoDOM({wasmURL, wasmExecURL?}) (wasm_exec already loaded in normal harness), mountGoDOM(root,facade) after load; renderer API matches existing mountKeyedDOM/React. `registry.mjs` exports descriptor(name,mount,manifest), createNegotiatedHost(root,runtime,descriptors,transport,initialBackend,manifest). Descriptor fields name,protocol,version,capabilities,methods,mount. Reject incompatible protocol/version/missing capabilities/declared methods BEFORE underlying runtime.init/mount/transport activity; descriptor claims don't prove implementation, returned API checked after mount. Layer manifest-driven bounds/kinds and inherited keyed validation around all snapshots for every backend. Pass failure notification through wrapped facade. Reuse unchanged keyed-editor/host.mjs, DOM/React renderers, HTTP transport, original Go collection/WASM. Do not change old sources.
