# E1 — Go renderer contract

Status: API and native CLI compile freeze published for E2/E3/E4 consumers.

## Delivered API

Package `github.com/samuelpmahan/gondola/rendercontract` exports:

- `DefaultManifest() Manifest`
- `ParseSnapshot([]byte) (Snapshot, error)`
- `ValidateSnapshot(Snapshot) error`
- `Manifest` with JSON fields `protocol`, `version`, `capabilities`, `methods`, `tags`, `attributes`, `events`, `nodeKinds`, `keyPattern`, `maxDepth`, and `maxNodes`
- `Snapshot` with lower-case envelope fields `state`, `tree`, `bindings`, and `messages`; the nested Gobi and inputbinding types retain their existing Go field casing

`ParseSnapshot` rejects malformed/trailing JSON, duplicate fields at every object depth, missing/extra or wrong-case fields, wrong primitive/null types, and invalid state/tree/binding/message structures. It returns only snapshots that pass `ValidateSnapshot`.

`ValidateSnapshot` enforces root depth zero, at most 64 depth and 4096 total nodes, unique ASCII element keys, node kinds 1/2, tags `div`, `p`, `input`, and `button`, the five manifest attributes, empty structured styles, click-only literal handlers, text-input rules, and `inputbinding.Validate`. Ordinary null `Attrs`, `On`, `Kids`, and `Attr.Style` slices remain accepted; `bindings` and `messages` must be non-null arrays.

`cmd/render-contract manifest` emits the Go-owned manifest. `cmd/render-contract validate` reads one snapshot from stdin, emits `{"valid":true}` on success or `{"valid":false,"error":"..."}` on failure, and returns nonzero for invalid input.

## Verification

Go toolchain: `go version go1.24.0 linux/amd64` (`/tmp/gondola-go/bin/go`).

Test-first RED checks observed before implementation:

- `/tmp/gondola-go/bin/go test ./rendercontract` failed to compile because `DefaultManifest`, `ParseSnapshot`, `ValidateSnapshot`, and `Snapshot` were not yet defined.
- `/tmp/gondola-go/bin/go test ./rendercontract ./cmd/render-contract` then reported the expected CLI RED: `undefined: run`; the contract tests passed after the package implementation existed.

One intermediate manifest test caught `[]uint8` being encoded as base64 by `encoding/json`; `nodeKinds` was changed to `[]int` and now serializes as `[1,2]`.

## Boundaries

This validates the bounded serialized v1 tree contract. It does not prove browser DOM reconciliation, focus restoration, callback cleanup, or application-state transitions. State remains opaque JSON. Fragments, structured styles, arbitrary HTML tags/attributes, and non-click literal handlers remain outside v1.
