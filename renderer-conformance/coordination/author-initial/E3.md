# E3 — JS admission adapter and negotiated host

Status: adapter, manifest-driven admission, and negotiated host are implemented and frozen for downstream integration.

## Public API

- `adapter.mjs` exports `loadGoDOM({ wasmURL, wasmExecURL? })` and `mountGoDOM(root, facade)`. The loader reuses an already-loaded global `Go`, starts the WASM runtime, waits for `globalThis.gobiGoDOM`, and checks the bridge method shape. The mount adapter forwards the host facade unchanged, including `rendererFailed`, exposes the renderer API expected by the keyed host, and unwraps exact `{ error: string }` bridge results.
- `protocol.mjs` exports `validateManifest()` and `validateSnapshotAgainstManifest(snapshot, manifest)`. It composes the unchanged keyed-editor validator with the Go-generated manifest's node kinds, tags, attributes, events, key pattern, maximum depth, and maximum node count. The generated v1 profile excludes fragments.
- `registry.mjs` exports `descriptor(name, mount, manifest)`, `validateNegotiation(descriptors, manifest)`, and `createNegotiatedHost(root, runtime, descriptors, transport, initialBackend, manifest)`. Descriptor protocol, version, capability, method, name, and initial backend checks complete before the underlying host can call `runtime.init()`, renderer mount, or transport methods. Actual API methods are checked after mount; metadata declarations do not prove implementation behavior.

The negotiated host passes the original runtime object to unchanged `createKeyedHost`, preserving its singleton lease against both old and negotiated hosts. Manifest checks wrap renderer `init`/`dispatch`, `update`/`snapshot`, and the public host `snapshot`; invalid initial snapshots are rejected before the candidate renderer's mount can mutate the DOM. The existing keyed host still owns runtime lifecycle, HTTP effects, and failure cleanup.

## Test-first evidence

The initial focused tests failed on the missing E3 exports before implementation:

- `/tmp/gondola-node22/node_modules/node/bin/node --test renderer-conformance/protocol.test.mjs` failed both tests because `validateSnapshotAgainstManifest` was absent.
- `/tmp/gondola-node22/node_modules/node/bin/node --test renderer-conformance/registry.test.mjs` failed on the missing `descriptor`/host API.
- `/tmp/gondola-node22/node_modules/node/bin/node --test renderer-conformance/adapter.test.mjs` failed on missing `loadGoDOM` and `mountGoDOM`.

A later regression test for mixed old/new host ownership also failed with `Missing expected exception` while the negotiated host wrapped the runtime object. Passing the original runtime through fixed both creation orders; the regression now passes.
