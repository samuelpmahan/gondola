# T3 — nested composition host

## Result

Implemented `createSessionTreeHost()` using the existing `createMultiRootHost`. Each Go-owned session mounts into a renderer-owned `viewRoot` beside a separate `childrenRoot`; descendants remain physically mounted when an ancestor renderer is replaced. The public host surface matches `DESIGN.md`, and mount records expose `{sessionID, parentID, depth, shell, viewRoot, childrenRoot}`. `transportFactory` receives `(sessionID, viewRoot, generation)`.

The adapter scopes root/child allocation to a guarded synchronous mount, blocks structural reentry, checks allocated parent/depth against Go's authoritative tree, and rolls back failed mounts. Subtree disposal validates host ownership before mutation, fences every descendant before `disposeTree`, then unmounts leaf-first while continuing cleanup after failures. It returns the Go postorder Disposal bundles intact, including cancel command `Value: ""`, and does not invoke raw leaf disposal after successful `disposeTree`.
