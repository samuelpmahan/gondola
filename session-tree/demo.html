Nested collection sessions

Each node is its own Go collection session and renderer. The family tree starts with a DOM parent, a React child, and a GoDOM grandchild. A separate root stays outside that subtree. Create deeper children, change a parent or child renderer, and hold saves in several sessions before disposing a branch.

This page uses the real HTTP lab: cancellation aborts that session’s request and a late release should return HTTP 409. The deterministic replay uses manual transports to compare exact start, cancel, and delivery order; it is a separate test from this HTTP-backed walkthrough.
