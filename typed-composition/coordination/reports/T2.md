# T2 — WASM bridge and native replay

## Result

Implemented the `gobiComposition` WASM wrapper and the matching native action replay command. The bridge exposes the exact public method set from `typed-composition/DESIGN.md`, enforces exact arity, primitive field types, closed own-field schemas, and positive safe IDs/revisions, and reuses the existing HTTP codecs. The native replay records one result and full post-action frame per action. No integrated browser/native oracle or inherited runner success is claimed here.

## Implementation

- Added `cmd/composition-wasm`. The browser global exposes create/createChild/tree/list/snapshot/dispatch/effects/complete/audit/dispose/disposeTree/setChildInputs/publish/changes/encodeHTTP/decodeHTTP. Snapshot, publication, tree, and manager behavior remain Go-owned.
- The WASM boundary rejects boxed primitives, wrong arity, unknown own properties (including symbols and non-enumerable fields), throwing proxies/getters, and malformed step/reply/input objects. Session, row, revision, request, and status numbers are checked without coercion. `Title` also rejects lone UTF-16 surrogates before converting to Go UTF-8.
- Added `cmd/composition-replay`, which accepts a closed `{ "actions": [...] }` JSON document from a file or stdin and emits `{ "frames": [...] }`. Each action result is followed by the complete manager tree, every live session snapshot in ascending ID order, and drained sorted changes. Failed action calls still yield frames so unchanged state can be compared. Effects, audit, and disposal outputs are captured as the action result rather than queried again during frame capture.
- Added the authoritative method/argument/frame contract at `typed-composition/coordination/WIRE.md`. Native replay JSON numeric arguments use canonical unsigned decimal integer tokens; the browser boundary accepts primitive Number values when they are safe integers.
- Added a Chromium browser smoke that exercises every method's arity check, malformed closed schemas, symbol/hidden fields, hostile getters/proxies, primitive safe IDs, and an unpaired title surrogate. Added native bridge parser tests and replay frame tests.

## Limits

This report covers the bridge and replay command only. It does not claim the full inherited session-tree runner, cross-implementation oracle, host propagation, or demo passed. The native replay validates its JSON input before executing actions; a malformed action document therefore produces no partial output. No parent authentication or transport-delivery guarantee is added.
