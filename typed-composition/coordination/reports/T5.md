## Implementation

- `typed-composition/fixture.mjs` mounts actual Go/WASM composition candidates through DOM, React, and GoDOM, alongside an independent pinned React reference. Script `dispatch` actions reach mounted native input/click controls; the readonly-disabled suppression case additionally validates the canonical manager call.
- `typed-composition/check.mjs` replays the shared `{actions:[{method,args}]}` wire through native Go replay, the independent JavaScript model, and both browser actors. It compares full operation results, manager frames, typed snapshots, trees, bindings, messages, inbox receipts, actual DOM/live disabled controls, effects, lifecycle, and dirty IDs. Each complete raw script is written to a SHA-256 indexed shard; mismatch artifacts are full and untruncated.
- Checker controls prove wrong-parent and stale-revision calls reject without state or dirty changes, inbox reordering is detected, and mutating the candidate's actual readonly DOM `disabled` property is detected.
- The fixture records requested and effective single-line input values. It verifies the actual browser `input.value`, input event value, and dispatched Go `Step.Value` agree with the declared effective value.
- The candidate renderer-replacement witness captures the logical focused keyed row and backward noncollapsed selection immediately after `replace()` returns and again after settling.
- A separate browser lifecycle probe retains a pending transport callback, disposes the old tree, creates fresh IDs, and invokes the old callback. It checks the actual Go manager received zero `Complete` calls and that all fresh snapshots, DOM, inbox/messages, and dirty IDs stayed unchanged.
- Source pinning now includes all production and test Go sources in the typed composition dependency path plus Go module and pinned browser dependency metadata. Missing pins fail the check instead of silently becoming `null`.
