## Implementation

- The browser demo mounts a parent and direct child through `createCompositionHost`, uses the real loopback HTTP lab for child saves, and exposes parent-owned Title/ReadOnly inputs through `setChildInputs`.
- DOM, React, and GoDOM renderers can be applied to each session. The demo remembers the child input's logical label and selection before a toolbar action and restores it before renderer replacement, allowing the keyed renderer to preserve focus and selection.
- A held child HTTP save can be completed while the child is read-only. The UI shows disabled collection controls during that policy, then allows a saved row to publish through Go into the parent's Inbox. The receipt panel reads the parent's Go snapshot and remains visible after child disposal; a replacement child receives a fresh session ID.
- The browser smoke asserts parent policy propagation, real held HTTP request completion under read-only mode, DOM/GoDOM/React state and selection retention, parent Inbox publication, retained receipt after disposal, and fresh-ID recreation.
- `run-typed-composition.sh` begins with `run-session-tree.sh`, then builds composition and GoDOM WASM, native replay, HTTP lab, React/reference bundles, runs focused Go test/race/vet gates and both WASM smokes, runs composition Node tests and the browser walkthrough, then invokes the seeded browser/native oracle. The workflow installs the supported toolchain and browser dependencies and uploads build artifacts.

## Initial smoke failures and fixes

- The first browser run failed the focus assertion (`browser-smoke.mjs:179`, `focused: false`). The toolbar selector and button had taken focus away from the child input before replacement. The demo now records the logical input label and selection on view focus events, restores that input before replacement, and lets the renderer restore it into the new backend.
- The second browser run reached the end of the walkthrough but reported an HTTP 409 in the browser console. The held-request release button had both a direct listener and a delegated listener, so a click issued two releases. The direct listener was removed; the delegated listener now releases once. The subsequent browser smoke passed with no page errors.
- An early focused Go run exposed the T2 decoder test accepting JSON `ID: 7.0`. The bridge author fixed the decoder; the focused Go, race, and vet commands above pass on rerun. The bridge lane retains its own detailed report and receipt.
