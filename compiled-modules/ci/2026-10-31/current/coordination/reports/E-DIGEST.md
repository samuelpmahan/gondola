# E-DIGEST — Go/JavaScript ABI digest parity

**Worker:** N3  
**Outcome:** `mixed_change`

## Change

Updated the JavaScript ABI validator’s canonical JSON encoding to match Go `encoding/json.Marshal`: string values and object keys escape `<`, `>`, `&`, U+2028, and U+2029 as lower-case `\\uXXXX`. String ordering used by canonical object keys, TypeInfo closure, artifact paths, and set comparisons now compares UTF-8 bytes, matching Go string ordering. The test fixture canonicalizer uses the same rules. No Go API or descriptor schema changed.

The artifact inventory requires exactly four paths under one `apps/<appDir>/` prefix, with the fixed ASCII basenames `app-ir.json`, `components.gen.mjs`, `encoder.mjs`, and `gobi-compiled.mjs`. For this accepted inventory, the directory prefix is common to every path and basename ordering is fixed ASCII; Unicode in that prefix cannot change the relative order. The validator nevertheless uses the Go-compatible byte comparator for the full accepted path strings.

## Regression evidence

The regression test uses five fixed golden pairs generated by Go 1.24 `encoding/json.Marshal` from the same test descriptor shape; it does not derive expected values using the JavaScript helper. Against the preserved pre-fix validator (SHA-256 `a392febf57509bc61c0f221e74429c0f6e268540ac2b675e931e5dc6396a16bd`), Node reported 6 passing tests and 1 failing canonical-vector test. The first `<` case failed with `artifact inventory digest mismatch`, reproducing the cross-language mismatch. After the change, the Node suite passes 7/7, including all five vectors.

## Actual artifact check

An independent Go witness used `moduleabi.Describe` and `ValidatePair` on the actual prior React parent and child output bytes. For each of the five path characters it generated Go descriptor sidecars under the altered but accepted output directory, then the Node validator admitted both descriptors against those same actual artifact bytes. All five parent and child ABI hashes matched between Go and Node. The ampersand parent artifact digest is `5b06301c98ba13f13fe2d32505877634d5da523b407304c1265a3487d8767112`, exactly the Go digest in the XR-ABI failure witness; the previously failing path now admits.

The witness inputs are the historical React build artifacts recorded in the stable build index. `actual-artifact-pins.json` hashes the 20 files for the four historical React/DOM module builds, and confirms those entries match the build index. These are prior artifacts captured before the separate UTF-8 compiler repair; this packet establishes digest compatibility and does not claim fresh producer, UI, or end-to-end acceptance.

## Verification and limits

Node v22.23.4 syntax checks and `compiled-modules/abi/validate.test.mjs` passed; Go 1.24.0 `go test -count=1 ./moduleabi` passed. Exact command arguments and output hashes are in `rawlogs/E-DIGEST/verification.json`; raw files are listed in the packet’s rawlog index. The active native receipt validator accepted E-DIGEST/N3, and the native state SHA-256 was unchanged across that read-only check. No Git state was changed. SHA-256 confirms supplied-byte consistency, not publisher authenticity or malicious-code isolation.

The original XR-ABI report and receipt remain unchanged with decision `amend`; E-DIGEST records the bounded repair and evidence that closes that canonical-JSON finding.
