## Frozen contract

New package `asyncsave`. State embeds editor.State (JSON flattened Draft,Saved,Saves) plus NextID uint64, PendingID uint64, Status string. Init Status="idle", IDs0. Maximum ID bounded to JS safe integer 9007199254740991; reject allocation exhaustion atomically. IDs monotonically increase across Reset to prevent stale ID reuse. Reply{ID uint64,Value string,Error string}. Command{Kind string,ID uint64,Value string}; Kind only "start" or "cancel".

Session NewSession(), Snapshot() original JSON {state,tree,bindings,messages}; Dispatch(gobi.Step)(Snapshot,error), Complete(Reply)(Snapshot,error), Effects()[]Command drains pending outbox, Audit()[]Outcome copied cumulative typed completion receipts. Every valid Complete call appends message {Name:"reply",Arg:decimalID} and Outcome even if stale; invalid input is atomic. Duplicate/stale/cancelled replies never change application state, but remain observable in history/audit.

Dispatch uses inputbinding.Resolve. edit sets Draft to Arg; save nonempty retires previous PendingID via cancel command, increments NextID, sets PendingID=NextID, Status="pending", start command captures exact draft. cancel if pending emits cancel, clears PendingID, Status="cancelled", retains editor fields. reset emits cancel if pending, clears editor.State and PendingID, Status="idle", preserves NextID. Disabled actions send nothing. Active Reply success stores Value exactly in Saved and increments Saves, clears PendingID, Status="saved"; error preserves Saved/Saves, clears PendingID, Status="error: "+Error. Stale Reply changes no State. View starts with editor.View(state.State) preserving input0, Saved p1, Saves p2, Save3, Reset4. Reset enabled if ANY app work/nonidle status (including pending/cancelled/error), not merely editor fields; NextID alone does not enable it.
