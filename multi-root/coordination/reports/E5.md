# E5 — Three-session deterministic replay and native oracle

## Delivered

- `multi-root/scripts.mjs` defines fixed three-root witnesses and deterministic
  seeded schedules for `20261030` and `20261031`. Fixed scripts cover matching
  local row/request IDs, simultaneous held saves, late reply rejection after
  disposal, sibling continuation, root reuse and repeated mount/dispose,
  per-root focus, every directed backend change, and renderer-failure
  isolation.
- `multi-root/reference.mjs` provides an independent reference manager with
  one `createCollectionReference` application model per session, plus the
  browser-mounted React reference application. The Go/WASM manager remains the
  candidate under replay.
- `multi-root/check.mjs` is an executable browser replay CLI, report checker,
  and native-envelope driver. It captures every root/actor after each action,
  writes native frame inputs, compares application/DOM/transport/lifecycle
  channels, and exits nonzero on scenario, parity, or native mismatch.
- `multi-root/check.test.mjs` probes missing actors/channels, session aliasing,
  synchronized no-op dispatch, event order, disposed-session revival, empty
  native frames, focus preservation, and collapsed versus directional
  selection. `scripts.test.mjs` checks deterministic seeds, schedule bounds,
  and that generated saves target nonempty drafts. `reference.test.mjs` checks
  same-ID isolation and disposal/reuse.
- `multi-root/TRACE.md` documents the observation schema, CLI, cancellation
  settling rule, and native `compare-interaction` input envelopes.

## Repair history and limits

Three compact failure summaries preserve the earlier failures and reproduction
details:

- [`replay-failed-75.json`](../../evidence/replay-failed-75.json) records the
  initial fixed-only report and exact mismatch array.
- [`replay-failed-default-cancel-race.json`](../../evidence/replay-failed-default-cancel-race.json)
  records 1,938 generated-run mismatches where asynchronous server cancellation
  was observed after the immediate capture.
- [`replay-failed-default-focus-direction.json`](../../evidence/replay-failed-default-focus-direction.json)
  records 58 later mismatches: collapsed-caret direction differences and one
  generated empty-draft save.

The final replay waits up to 10 seconds after a repeated save for the new held
request and each prior held request's server-side `cancelled` state. A timeout
fails the replay. Transport event order is still compared. Selection direction
is canonicalized only when start equals end; non-collapsed backward/forward
selections remain exact parity checks. The generator now tracks its fallback
fill value and tests prevent it from scheduling a save on an empty draft.

Renderer failure isolation in replay uses a rejected unknown-renderer request;
actual throwing-renderer teardown is covered by the E4 host tests. This finite
run uses one Chromium build and the loopback HTTP lab. It does not cover IME,
other browser engines, pixel equivalence, production HTTP services, or
concurrent browser scheduling. The integrated `bash run-multi-root.sh` and
repository preservation/review gates are outside this E5 verification.
