# E1 — Native Rebalancer session manager

## Result

Implemented multisession.Manager over the existing collection.Session without changing collection behavior. SessionID is a distinct type, allocation starts at 1, IDs are monotonic and capped at JavaScript's safe-integer maximum, and List returns active IDs in ascending order. Every state, effect, completion, and audit operation is addressed to one live session. Dispose returns cancel commands for pending rows in current row order, then removes that session; calls for unknown or disposed IDs return errors.

The manager serializes access with a mutex. Snapshot trees, state, messages, bindings, effects, audits, and ID lists are isolated from caller mutation. Tests cover same-numbered row/request IDs across sessions, scoped dispatch/effects/completions/audits, disposal and late calls, deterministic listing, safe-ID exhaustion, and mutation isolation.
