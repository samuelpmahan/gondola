# E2 — Strict multi-session WASM bridge

## Result

Implemented `globalThis.gobiMultiRoot` with the exact methods `create`, `snapshot`, `dispatch`, `effects`, `complete`, `audit`, `dispose`, `list`, `encodeHTTP`, and `decodeHTTP`. Session IDs must be primitive positive safe-integer numbers. Every method checks exact arity and returns bridge failures as exactly `{error: string}`. Dispatch and completion inputs require the exact own-field sets and primitive field types; unknown fields, symbol keys, non-enumerable extras, throwing getters, and hostile `ownKeys` proxies are rejected. The bridge routes all collection operations through `multisession.Manager` and uses the existing `httpwire` codecs.

Added native tests for exact JSON object decoding, duplicate and escaped duplicate keys, required and unexpected fields, primitive string shapes, reply ID notation/range, and safe session ID numeric bounds. Added a Playwright Chromium smoke that starts the real Go/WASM bridge in a browser, keeps three sessions active at once, uses request ID 1 in each, disposes one session while pending, rejects its late callbacks, verifies sibling completion/audit isolation, and checks arity and malformed-input fences.
