Three Go sessions, one browser realm

Each panel owns an independent session, renderer, and HTTP lane. Hold saves in two panels at once, change a single panel's renderer, and dispose a panel with a save still held. The surviving session stays usable; releasing the disposed session's request is rejected. Remounting that panel creates a fresh session.

For the clearest walk-through, use DOM in Root A, React in Root B, and GoDOM in Root C. Renderer choices are local to their panel.
