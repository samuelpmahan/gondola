# XR-G-REACT

**Decision: amend.** The generic React mapping is source-derived: `emit.Backend.Emit` validates AppIR and calls `reactmap.Generate()`, whose attribute and boolean tables come from the existing Gobi tables. The configured `gobi.Backend` adapter checks captured app identity at Emit time and emits cached AppIR metadata; no application reducer or fixture logic appears in `emit/**` or `frontend/react/**`. `bindCompiledComponent` returns the exact own data function values selected by AppIR Init/Update/View IDs. Renderer tests cover React key mapping, child paths, keyed identity scopes, live `target.value` and `target.checked`, preservation of literal `On.Arg`, stale closure epochs, and accessor/hidden-field rejection.

Focused tests passed during review: `GOTOOLCHAIN=go1.27.3 /tmp/gondola-go/bin/go test -count=1 ./emit` (4/4), plus the N3 Node command (14/14). Installed React and ReactDOM resolve to 19.3.1; the generated map matches `reactmap.Generate()` via the Go test. N1’s ABI report says an observed GoSlice has own data fields `backing, offset, length, capacity, target`, with `target: undefined`.

Two integration defects remain. First, renderer `listOrEmpty()` accepts a GoSlice missing `target`; an inline `lowerView` probe accepted a Node.Kids wrapper with only the four core fields. The test helper also defaults to this unobserved shape. Second, renderer callbacks send `{Path,Event,Value}`, but the current runtime accepts only `{path,event,value}`. A focused lowerView-to-runtime probe failed at `dispatch-input` and left the trace at its init tick. Runtime also cannot record late stale attempts after this renderer’s unmount clears `current` and makes `viewRecord()` return null / `domSnapshot()` fail. These cross-lane issues need reconciliation before end-to-end integration. No browser mount was tested here; N6 remains the browser gate.
