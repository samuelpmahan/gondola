# A-ABI

**Outcome: `confirmed_reuse`, scoped to the probed GoScript ABI.** I read `semantic/ABI.md`, the probe sources, emitted TypeScript, raw Node/native JSON, module-origin record, and checksum manifest. Pinned `goscript` is v0.6.2 at commit `d8f58a091947cff26a9171be7bd130892b0afad3`; current `go.mod` and `go.sum` also pin v0.6.2. The cached compiler source confirms `SemanticModel`’s type/function/package maps are unexported, while `CompilationResult` exposes package lists, diagnostics, and optional async report only. The report correctly says no public typed symbol/type/call metadata API was observed; typed input must come from AST plus `go/types`.

The emitted raw counter `Update` mutates its argument and returns the same object. The emitted forwarding adapter calls `counter.Update((state).clone(), message)`; raw Node output records caller count 0, result count 1, different identities. Native and Node projections independently match across counter, snapshot, formatter, and `Node.Set` fork data. Forwarded nested structs/arrays copy; slice element writes remain shared. Appending `[]Inner` with no spare capacity yields input length 1/count 13 and output length 2/counts 113,15; `[]float64` append yields a wrapper backed by `Float64Array`. Nil versus empty is distinct for all six fixture slice types, and float negative zero remains `8000000000000000`.

Representation is supported for the sampled values: `int`/`uint` and narrower integers are Number; `int64`/`uint64` are BigInt. Boundary outputs show `int64`/`uint64` do not wrap, and Number-backed host `int`/`uint` can leave the safe range. Do not admit these operations without an analyzer gate. The probe directly exercises GoSlice wrappers for `[]Inner`, `[]float64`, and Gobi Node Attrs/On; it does not append every ordinary slice element type.

**Evidence limits:** `sha256sum -c toolchain/probe_counter/results/SHA256SUMS` passed all 22 listed entries. The current runner’s checksum input list additionally names five files absent from that manifest: `go.mod`, `go.sum`, `package.json`, `package-lock.json`, and `semantic/ABI.md`; their current hashes are recorded in the receipt. The ABI report says unsafe integer operations are rejected, but the current `analyze/` files are only source loading/projection/type collection and contain no numeric range validator yet. Treat that as a required future gate, not verified behavior. This audit does not prove four-app builds, React, effects, or browser conformance.
