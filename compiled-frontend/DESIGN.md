## Frozen semantic requirements

Version1 contracts use lowerCamel JSON, explicit required fields, ordered arrays, source-relative spans and closed validators. N2 owns exact Go/JSON/JS API publication at CONTRACT.md before consumers commit to it. Model AppIR with typed component Init/Update/View symbols and capabilities, diagnostics, build request/result, canonical trace and deterministic host script. Reject missing/extra fields, unknown versions/capabilities, wrong signatures and unsupported reachable calls with source locations. Do not claim full goscript IR or Go-statement source maps.

Trace captures initialization and every attempted action plus actual reply dispatches. Required tick fields include index, nullable action/message/dispatch identity, exact type-aware state, requested/completed effect records, tree and browser DOM where required. Preserve nil versus empty slices, exact strings/order and float64 IEEE bits including negative zero. Non-finite and unsupported numeric/library semantics fail explicitly. Native state encoding may use an independently implemented Go type-aware encoder; emitted JS encoding must be generated from Go type information and actual probed representation. No generic lossy JSON state conversion. Effects correlate dispatchId/effectIndex; HostScript rejects missing, extra, reordered or mismatched requests/completions. State/view commit must be physically observable before reply completion; exactly-once delivery and stale/unmounted callbacks are tested. DOM claims explicitly describe normalization and required live values/checked/disabled properties.

React lowering preserves Node keys/attributes/styles and literal On.Arg; explicit targetValue and targetChecked bindings read actual targets, checked exactly true/false strings. Duplicate event names across literal and bound handlers, duplicate sibling keys, invalid binding targets, unknown events/effects, and stale detached callbacks fail. React StrictMode cannot reinitialize Go or duplicate effects. Use synchronous serialized React commit for this profile; do not claim concurrent scheduling equivalence.
