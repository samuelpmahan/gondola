## Delivered

The interactive page composes the existing effect host and existing DOM/React renderers with `createHTTPTransport` against the same-origin Go lab. It exposes response modes, held-request release, the Go snapshot and completion audit, transport events, renderer/live DOM details, and the server's request records. Cancel aborts the actual fetch, and the server log shows whether it observed cancellation.

The Playwright smoke starts the built Go lab and verifies a held request through a DOM-to-React swap, accepts its released HTTP success, exercises a server error and fresh-ID retry, exercises a malformed reply and retry, then cancels a second held request and checks the server cancellation record. It saves the inspectable pending state to `http-effects/build/demo-pending-swap.png`.

The default runner calls `run-async-effects.sh` before building the new WASM/server assets, bundling the already-pinned React renderer and independent reference, running Go and Node tests, driving the real-HTTP demo, and invoking the seeded browser harness. `GONDOLA_HTTP_SKIP_INHERITED=1` is available only with a prior successful receipt whose inherited-source digest still matches. CI uses Go 1.24, Node 22, pinned interaction dependencies and Playwright Chromium, and uploads inherited plus HTTP artifacts. No npm dependencies were added or changed.
