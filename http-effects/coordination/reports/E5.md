## Delivered

The demo composes the existing effect host and existing DOM/React renderers with `createHTTPTransport` against the same-origin Go lab. It exposes response modes, held-request release, the Go snapshot and completion audit, transport events, renderer/live DOM details, and server request records. Cancel aborts the actual fetch; the server log shows whether it observed cancellation.

The Playwright smoke starts the built Go lab and verifies a held request through a DOM-to-React swap, accepts its released HTTP success, exercises a server error and fresh-ID retry, exercises a malformed reply and retry, then cancels a second held request and checks the server cancellation record. It saves the inspectable pending state to `http-effects/build/demo-pending-swap.png`.

The default runner now executes `run.sh` (signed static M0 baseline), then `run-async-effects.sh` (the inherited backend, renderer, input, and async-effects gates), before building the HTTP WASM/server assets and running the new checks. The inherited receipt digest includes source/config inputs and every path listed in `SHA256SUMS`; generated/build/evidence directories are excluded. The opt-in `GONDOLA_HTTP_SKIP_INHERITED=1` path skips both inherited gates only when a passing receipt matches the current digest. CI uses Go 1.24, Node 22, pinned interaction dependencies and Playwright Chromium, and uploads backend-replacement, inherited, and HTTP artifacts. No npm dependencies were added or changed.
