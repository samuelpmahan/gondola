## Contract delivered

- `httpwire.EncodeRequest(id, value)` emits `{"ID":N,"Value":...}` with stable field order and rejects ID zero, IDs above `asyncsave.MaxID`, and invalid UTF-8 values.
- `httpwire.DecodeResponse(id, status, body)` always uses the expected ID. Non-200 status returns `http status N`; a 200 response must be at most 65,536 bytes and contain exactly one correlated `{ID,Value,Error}` object. Duplicate decoded property names (including escaped aliases), missing/extra fields, wrong primitive types, unsafe/non-integer IDs, malformed UTF-8/Unicode escapes, trailing JSON, and wrong IDs return `invalid response`.
- The new `gobiHTTPSave` WASM global exposes `init`, `dispatch`, `complete`, `effects`, `audit`, `encodeHTTP`, and `decodeHTTP`. All methods enforce exact argument counts. HTTP methods enforce primitive JS types, positive safe integer IDs, and status 100–599. `encodeHTTP` returns the JSON request string; `decodeHTTP` returns `{ID,Value,Error}`. Invalid bridge calls return the established `{error: string}` result shape.
