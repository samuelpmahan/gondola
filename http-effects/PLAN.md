## Integration clarifications

Final codec rejects unpaired escaped UTF-16 surrogates as invalid response data; valid pairs are accepted. Browser body text is a string boundary, distinct from native raw UTF-8 byte validation. HTTP transport URL may be a synchronous command-to-URL resolver to select lab modes. Live held release returns202; canceled/completed/duplicate releases return409 without mutating retained terminal records. Server request State may transiently be processing before a terminal record. The physical aborted socket cannot deliver a late body; injected fetch-race tests and inherited Go completion guards establish separate late-callback/reply checks. The reference uses mountHTTPReference wrapping the independent React renderer, not the candidate renderer.
